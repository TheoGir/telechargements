HEAPS

Le prochain coup vous appartient.

Le jeu de piles en 3D, contre une IA de quatre niveaux. Gratuit, sans compte, sans publicité.

Jouer maintenant

Directement ici, rien à installer.

  1. Touchez le bouton Partager en bas de Safari (carré avec une flèche).
  2. Choisissez Sur l'écran d'accueil, puis Ajouter.

Autres façons de l'avoir

Application Windows classique : heaps-windows.exe. Elle s'installe sans droits administrateur et se met à jour toute seule. Si Windows affiche « Windows a protégé votre ordinateur », cliquez sur « Informations complémentaires » puis « Exécuter quand même » : le jeu vient d'un petit créateur, pas d'un éditeur payant.

Sur Android : dans Chrome, menu ⋮ puis « Installer l'application ».

Vos parties restent sur votre appareil : rien n'est envoyé nulle part.
