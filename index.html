Le prochain coup vous appartient.

Nim, Wythoff, Flora et vos propres règles dans une arène 3D, contre une IA de quatre niveaux. Gratuit, sans compte, sans publicité.

Jouer maintenant

Directement dans le navigateur, sur ordinateur, tablette ou téléphone. Rien à installer.

 Télécharger pour Windows

L'appli complète, qui fonctionne sans Internet et se met à jour toute seule.

L'ajouter comme une appli

  • Sur ordinateur (Chrome ou Edge) : ouvrez le jeu, puis cliquez sur l'icône « Installer » au bout de la barre d'adresse.
  • Sur Android : ouvrez le jeu dans Chrome, menu ⋮, puis « Ajouter à l'écran d'accueil ».
  • Sur iPhone et iPad : ouvrez le jeu dans Safari, bouton Partager, puis « Sur l'écran d'accueil ».

Le jeu marche ensuite même hors ligne, et chaque nouvelle version arrive toute seule.

Installation Windows

  • Au premier lancement, Windows peut afficher « Windows a protégé votre ordinateur », parce que le jeu vient d'un petit créateur. Cliquez sur Informations complémentaires, puis Exécuter quand même.
  • Ensuite, HEAPS propose lui-même ses mises à jour au démarrage.
Vos parties restent sur votre appareil : rien n'est envoyé nulle part.
